The DCDC we have (no fan) has its CAN ID as CAN5010

We sent ELCON an email and this was their reply:

"CAN5010 is 500Kbps. CAN5100 protocol is attached which is the same as CAN5010 except for the baud rate."

So the CAN datasheet in this folder has the same message IDs, just a different baud rate :D
